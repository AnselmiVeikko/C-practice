# C-practice

A collection of C++ exercises split into 10 modules.

- **Module 00** starts with the very basics of C++, including classes and object-oriented programming.
- The modules become progressively more advanced, introducing topics like inheritance and abstract classes.
- In later modules, I unlocked the **STL** and learned to use containers and build templates.
- **Module 09** is the finale: it contains 3 exercises where each one uses a different container.
- The final exercise focuses on merge sort using the **Ford-Johnson algorithm**.
